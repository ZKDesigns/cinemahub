# 🎬 Filmové žánry

Interaktivní webový průvodce filmovými žánry.  
Hezký, responzivní, s vyhledáváním a tmavým/světlým motivem.

## Co je uvnitř

- 12 hlavních žánrů s popisy
- Příklady kultovních filmů
- Živé vyhledávání podle názvu, popisu a filmů
- Přepínání světlého/tmavého motivu
- Modální okna s podrobnými informacemi
- Plně statický web — připravený pro GitHub Pages

## Jak spustit lokálně

Jednoduše otevři `index.html` v prohlížeči  
nebo spusť jednoduchý server:

```bash
# Python
python -m http.server 8000

# nebo Node
npx serve .
